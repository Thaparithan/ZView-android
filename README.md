# Z Scan: PDF Maker

This repository contains:
1. **`/android/`**: The complete, ready-to-open **Android Studio (Kotlin + Jetpack Compose + CameraX + Room + Material 3 + `PdfRenderer`)** native project for **Z Scan: PDF Maker** (short label: `Z Scan`, package: `com.zynor.zview`), also downloadable as `zview-android-project.zip` directly from the running application.
2. **`/src/`**: The interactive **Z Scan: PDF Maker** application running on port 3000, implementing the complete **Z Scan: PDF Maker** workflow including **Light / Dark / System Default** theme switching, **In-App Multi-Page PDF Viewer** (vertical scroll + single-page + native PDF stream renderer + zoom + page thumbnails), **Camera/Scanner** with 4-corner boundary crop, **Image Import**, **Original / Grayscale / B&W / Document Enhancement** filters, **Multi-Page PDF Creation & Export**, **Document Library**, **Settings** with `https://zynor-view.web.app/` **Personal Review & Feedback**, and the **Android Studio Source Explorer**.

See [`/android/README.md`](./android/README.md) for full Android Studio setup, Gradle build, and debug APK installation instructions.
