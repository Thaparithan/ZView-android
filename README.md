# ZView — Document Scanner & PDF Creator

This repository contains:
1. **`/android/`**: The complete, ready-to-open **Android Studio (Kotlin + Jetpack Compose + CameraX + Room + Material 3)** native project for **ZView**, also downloadable as a single `zview-android-project.zip` bundle directly from the running application.
2. **`/src/`**: The interactive **ZView Android Companion & Live Document Scanner / PDF Studio** running on port 3000, implementing the complete ZView experience (Home, Camera/Scanner with 4-corner boundary crop, Image Import, Original/Grayscale/B&W/Document Enhancement filters, Multi-Page PDF Creation & real PDF download, Local Persistent Document Library, Document Preview with zoom/thumbnails, Settings with `https://zynor-view.web.app/` Personal Review & Feedback, and full Android Studio Kotlin source code explorer).

See [`/android/README.md`](./android/README.md) for full Android Studio setup, Gradle build, and debug APK installation instructions.
